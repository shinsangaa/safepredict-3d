# SafePredict 3D - 가상 시나리오 명세서
- 문서명: `scenarios.md`
- 버전: v0.4 (시나리오별 랙 배치·카메라 시점 추가)
- 작성일: 2026-11-16
- 수정일: 2026-11-19
- 적용 범위: 지게차 1대·작업자 1명, S01~S06, 10Hz 가상 시뮬레이션

## 1. 문서 개요
### 1.1 목적
지게차와 작업자의 가상 이동 시나리오를 정의하고, 충돌 위험 계산 엔진의 TTC·DCPA·CRI 산출 및 위험 단계 판정 기능을 검증한다.

### 1.2 검증 범위
- 대상 객체: 지게차 1대, 작업자 1명
- 시나리오: S01~S06 (총 6종)
- 이동 방식: 등속 직선 이동 기반
- 예외: S05는 일정 시점에 방향 전환, S06은 지게차 회전
- 검증 대상: 거리, 상대속도, TTC, DCPA, 예측 CRI, 통합 CRI, 위험 단계, 경보 이벤트

## 2. 공통 시뮬레이션 조건
| 항목 | 설정값 |
|---|---|
| 좌표계 | 2D 직교좌표계 (x, y) |
| 좌표 단위 | m |
| 시뮬레이션 주기 | 10Hz |
| 시간 간격 | 0.1초 |
| 속도 단위 | m/s |
| 충돌 판정 거리 | 중심 간 거리 1m 이하 |
| 이동 모델 | 기본 등속 직선 운동(S06은 회전 포함) |
| 객체 높이 | z=0 (계산 기준점) |

- 지게차와 작업자는 초기 위치 및 속도 벡터에 따라 이동한다.
- 매 0.1초 마다 객체 위치와 충돌 위험 지표를 갱신한다.
- 시나리오 종료 시 이동 및 위험 계산을 중지한다.
- 시뮬레이션 시작·초기화 시 객체 위치와 경보 상태를 초기화한다.
- 충돌 판정 거리 1m는 PoC 검증용 임시 설정값이다.

## 3. 시나리오별 설정
| ID | 시나리오 | 지게차 시작위치 | 작업자 시작위치 | 지게차 이동 | 작업자 이동 | 실행시간 |
|---|---|---|---|---|---|---|
| S01 | 정상 이동 | (0, 0) | (10, 8) | +x, 2m/s | +x, 1m/s | 10초 |
| S02 | 정지 접근 | (0, 0) | (10, 0) | 정지, 0m/s | -x, 1m/s | 최대 10초 |
| S03 | 정면 접근 | (0, 0) | (10, 0) | +x, 2m/s | -x, 1m/s | 최대 5초 |
| S04 | 교차 이동 | (0, 0) | (10, 10) | +x, 2m/s | -y, 2m/s | 최대 6초 |
| S05 | 접근 후 이탈 | (0, 0) | (4, 0) | 정지, 0m/s | 0~2초: -x, 1m/s / 2~8초: +x, 1m/s | 8초 |
| S06 | 코너 회전 | (6, 4) | (12.5, 12.5) | +x 2.8m/s, 1.8~3.3초 좌회전 | -y, 1.1m/s | 최대 6초 |


### 3.1 S01 - 정상 이동
목적: 충돌 가능성이 없는 평행 이동 상황에서 오경보 발생 여부 검증
- 지게차와 작업자는 +x 방향으로 이동
- 두 객체 사이의 수직 간격은 8m 유지
- 실행시간: 10초
- 종료조건: 10초 경과

예상 결과
- 최소 거리: 8m
- TTC: 없음
- DCPA: 8m
- 위험 단계: SAFE 유지
- 경보: 발생하지 않아야 함

### 3.2 S02 - 정지 접근
목적: 정지한 지게차에 작업자가 접근하는 상황을 검증
- 지게차는 (0, 0)에 정지한다.
- 작업자는 -x 방향으로 1m/s 이동한다.
- 최대 실행시간: 10초
- 종료조건: 객체 중심 간 거리 1m 이하

예상 결과
- 초기 거리: 10m
- 초기 TTC: 9초
- DCPA: 0m
- 접근할수록 TTC 감소
- 위험 단계 상승 및 경보 발생 여부 검증

### 3.3 S03 - 정면 접근
목적: 두 객체가 서로 접근하는 상황에서 상대속도 및 TTC 계산을 검증한다.
- 지게차는 +x 방향으로 2m/s 이동
- 작업자는 -x 방향으로 1m/s 이동
- 최대 실행시간: 5초
- 종료조건: 객체 중심 간 거리 1m 이하

예상 결과
- 초기 거리: 10m
- 상대 접근 속도: 3m/s
- 초기 TTC: 3초
- DCPA: 0m
- 접근에 따라 CRI 상승 및 경보 발생 여부 검증

### 3.4 S04 - 교차 이동
목적: 두 객체가 서로 다른 방향으로 이동하면서 경로가 교차하는 상황을 검증한다.
- 지게차는 (0, 0)에서 +x 방향으로 2m/s 이동한다.
- 작업자는 (10, 10)에서 -y 방향으로 2m/s 이동한다.
- 경로 교차점: (10, 0)
- 두 객체 모두 5초 후 교차점에 도달하는 속도로 설정한다.
- 최대 실행시간: 6초
- 종료조건: 객체 중심 간 거리 1m 이하

예상 결과
- 초기 거리: 약 14.14m
- 초기 TTC: 약 4.65초
- DCPA: 0m
- 교차 지점에 접근하면서 위험도 상승
- 교차 경로 충돌 예측 및 경보 기능 검증

### 3.5 S05 - 접근 후 이탈
목적: 접근 중인 작업자가 방향을 전환해 멀어지는 상황에서 위험도 감소와 경보 해제 기능을 검증한다.
- 1단계: 접근 (0~2초 미만)
    - 지게차는 (0, 0)에 정지한다.
    - 작업자는 (4, 0)에서 -x 방향으로 1m/s 이동한다.
    - 2초 시점에 작업자는 (2, 0)에 도달한다.
- 2단계: 이탈 (2~8초)
    - 2초 시점부터 작업자의 이동 방향을 +x로 변경한다.
    - 작업자는 +x 방향으로 1m/s 이동한다.
    - 8초 시점에 작업자는 (8, 0)에 도달한다.
- 종료 조건: 8초 경과

예상 결과
- 초기 거리: 4m
- 초기 TTC: 3초 (방향 전환 이전의 등속도 예측)
- 초기 DCPA: 0m
- 방향 전환 후 TTC: 없음
- 방향 전환 직후 미래 DCPA: 2m
- 이탈 시 위험도 감소 및 경보 해제 여부 검증

### 3.6 S06 - 코너 회전
목적: 지게차가 회전하는 상황에서 등속 예측의 한계와 월드 모델 조기 경보를 검증한다.
- 지게차는 (6, 4)에서 +x 방향으로 2.8m/s 이동한다.
- 1.8~3.3초 동안 좌회전한다(코드 기준 약 96°).
- 작업자는 (12.5, 12.5)에서 -y 방향으로 1.1m/s 이동한다.
- 선반 (9.0, 8.5), 4.5m×4.5m는 화면 표시용이며 충돌 계산에 반영하지 않는다(시나리오별 배치는 3.7 참조).
- 최대 실행시간: 6초
- 종료조건: 객체 중심 간 거리 1m 이하

예상 결과
- 초기 거리: 약 10.70m, 초기 TTC: 없음, 초기 DCPA: 약 5.53m
- 현재 CRI만 사용: 3.0초까지 SAFE, 3.1초에 CRITICAL로 직행
- 3.6초에 거리 1m 이하로 종료
- 통합 CRI 사용: 1.8초에 WARNING, 2.2초에 CRITICAL (학습 횟수 300, 시드 42 기준)

### 3.7 화면 표시용 랙 배치
3D 관제 화면에 그리는 물류 선반(랙)의 위치다. 랙은 화면 표시용이며 충돌 위험 계산에 반영하지 않는다.

| ID | 랙 중심 (x, y) | 크기 (x방향 × y방향) | 차지하는 범위 |
|---|---|---|---|
| S01 | (10, 4.75) | 16m × 2.5m | x 2~18, y 3.5~6.0 |
| S01 | (10, -3.5) | 16m × 3m | x 2~18, y -5~-2 |
| S02·S03·S05 | (5, 5) | 12m × 3m | x -1~11, y 3.5~6.5 |
| S02·S03·S05 | (5, -3.5) | 12m × 3m | x -1~11, y -5~-2 |
| S04 | (5, 6.25) | 7m × 5.5m | x 1.5~8.5, y 3.5~9.0 |
| S04 | (14.5, 6.25) | 6m × 5.5m | x 11.5~17.5, y 3.5~9.0 |
| S06 | (9, 8.5) | 4.5m × 4.5m | x 6.75~11.25, y 6.25~10.75 |

- 랙 높이는 모두 2.5m다.
- 모든 시나리오에서 지게차·작업자의 이동 경로가 랙과 겹치지 않는다(경로와 랙 사이 간격 최소 1.25m).
- S01은 두 이동 경로 사이와 바깥쪽에, S02·S03·S05는 통로(y=0) 양쪽에, S04는 교차점 양옆에 배치했다.
- 코드 위치: `app.py`의 `SCENARIO_RACKS`

화면 중심과 카메라 거리도 시나리오별로 다르게 둔다.

| ID | 화면 중심 (x, y) | 카메라 수평 거리 |
|---|---|---|
| S01 | (10, 3) | 16m |
| S02·S03·S05 | (5, 0) | 12m |
| S04·S06 | (10, 8) | 18m |

- 카메라 높이는 수평 거리의 1.22배다.
- 위 값은 처음 화면의 값이며, 드래그 · Shift+드래그 · 휠로 바꿀 수 있다.
- 코드 위치: `app.py`의 `SCENARIO_VIEW`

## 4. TTC · DCPA 수동 검산 기준
TTC는 두 객체의 중심 간 거리가 최초로 1m 이하가 되는 미래 시점을 기준으로 계산한다.

DCPA는 현재 속도를 유지한다고 가정할 때 미래에 도달하는 최소 중심 간 거리로 정의한다.
| 시나리오 | 초기 거리 | 초기 TTC | 초기 DCPA |
|---|---|---|---|
| S01 정상 이동 | 약 12.81m | 없음 | 8m |
| S02 정지 접근 | 10m | 9초 | 0m |
| S03 정면 접근 | 10m | 3초 | 0m |
| S04 교차 이동 | 약 14.14m | 약 4.65초 | 0m |
| S05 접근 후 이탈 | 4m | 3초 | 0m |
| S06 코너 회전 | 약 10.70m | 없음 | 약 5.53m |

- S05의 초기 계산값은 최초 속도를 유지한다는 가정에 따른 결과이며, 방향 전환 시 재계산한다.
- 0.1초 간격으로 시뮬레이션하므로 실제 종료 시점은 이론적 TTC와 최대 0.1초 정도 차이가 발생할 수 있다.

## 5. 시나리오별 검증 기준
| ID | 검증 항목 | 통과 기준 |
|---|---|---|
| S01 | 정상 이동 및 오경보 | SAFE 유지, 경보 미발생 |
| S02 | 정지 객체 접근 | 거리·TTC 감소 및 위험 단계 상승 확인 |
| S03 | 정면 접근 | 상대속도 3m/s 및 초기 TTC 3초 검산 |
| S04 | 교차 이동 | TTC·DCPA 계산 및 교차 위험 검출 |
| S05 | 접근 후 이탈 | 방향 전환 후 위험도 감소 및 경보 해제 |
| S06 | 코너 회전 | 통합 경보가 현재 CRI 경보보다 먼저 발생 |

공통 검증 기준
- 초기 위치와 이동 속도가 명세와 일치해야 한다.
- 시뮬레이션 데이터는 0.1초 간격으로 생성한다.
- TTC·DCPA 계산 결과는 수동 검산값과 허용 오차 내에서 일치해야 한다.
- CRI에 따른 위험 단계가 일관되게 산출되어야 한다.
- 위험 상태 변경 시 이벤트가 기록되어야 한다.
- 동일한 시나리오를 반복 실행하면 동일한 결과가 재현되어야 한다.
