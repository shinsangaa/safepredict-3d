# SafePredict 3D - 요구사항 명세서
## 1. 프로젝트 개요
**프로젝트명:** SafePredict 3D

**목적:** 가상 산업현장에서 지게차와 작업자의 이동을 시뮬레이션하고, 객체 간 거리 · 상대속도 · TTC · DCPA · CRI를 계산하여 충돌 위험을 예측하고 3D 관제 화면에 시각화하는 PoC 개발.

**개발 범위**
- 지게차 1대, 작업자 1명
- 10Hz 가상 위치 · 속도 데이터 생성
- 물리 · 규칙 기반 충돌 위험 분석
- Three.js 기반 인터렉티브 3D 관제
- Streamlit 기반 대시보드 및 경보 이력 관리

| NFR-05 | 데이터 품질 | 필수값 및 좌표·시간 정합성 검증 | 전처리 단위 테스트 |
| NFR-06 | 재현성 | 동일 시나리오 입력에서 동일 계산 결과 | 반복 테스트 |

## 5. 위험 판정 요구사항
| 위험 단계 | CRI 범위 | 동작 |
|---|---|---|
| SAFE | CRI < 0.50 | 정상 표시 |
| WARNING | 0.50 <= CRI < 0.85 | 주의 경보 및 이벤트 기록 |
| CRITICAL | CRI >= 0.85 | 위험 경보 및 이벤트 기록 |

- CRI는 0~1 범위의 값으로 계산한다.
- TTC·DCPA 계산 시 접근·이탈 상태를 구분한다.
- 충돌 판정 거리와 안전 버블 기준은 시뮬레이션용 설정값으로 관리한다.
- 세부 계산식과 예외 처리는 `risk_rules.md`에 정의한다.
- 실제 산업현장의 안전 제어 기준으로 사용하지 않는다.

- 물리 · 규칙 기반 충돌 위험 엔진
