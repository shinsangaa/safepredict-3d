# SafePredict 3D - 요구사항 명세서
- 문서명: `requirements.md`
- 버전: v0.2 (월드 모델 통합)
- 작성일: 2026-11-16
- 수정일: 2026-11-17

## 1. 프로젝트 개요
**프로젝트명:** SafePredict 3D

**목적:** 가상 산업현장에서 지게차와 작업자의 이동을 시뮬레이션하고, 객체 간 거리 · 상대속도 · TTC · DCPA · CRI를 계산하고, 경량 월드 모델로 미래 궤적을 예측해 위험을 선제적으로 판정하며, 이를 3D 관제 화면에 시각화하는 PoC 개발.

**개발 범위**
- 지게차 1대, 작업자 1명
- 10Hz 가상 위치 · 속도 데이터 생성
- 물리 · 규칙 기반 충돌 위험 분석
- Three.js 기반 인터렉티브 3D 관제
- Streamlit 기반 대시보드 및 경보 이력 관리
- 경량 월드 모델 기반 미래 궤적 예측(2.5초)

## 3. 비기능 요구사항 (Non-Functional Requirements)
| ID | 항목 | 목표 | 검증 방법 |
|---|---|---|---|
| NFR-01 | 데이터 생성 주기 | 10Hz | 생성 타임스탬프 확인 |
| NFR-02 | 위험 계산 처리(예측 롤아웃 포함) | 100ms 이하 | 100회 이상 측정 |
| NFR-03 | 로컬 화면 갱신 | 1초 이내 | 브라우저 화면 확인 |
| NFR-04 | 클라우드 화면 반영 | 2초 이내 | 생성~표시 지연 측정 |
| NFR-05 | 데이터 품질 | 필수값 및 좌표·시간 정합성 검증 | 전처리 단위 테스트 |
| NFR-06 | 재현성 | 동일 시나리오 입력에서 동일 계산 결과 | 반복 테스트 |
| NFR-07 | 로그 완전성 | 발생한 경보 이벤트와 저장 로그 건수 일치 | 이벤트·로그 비교 |
| NFR-08 | 배포 환경 | Docker 로컬 검증, Streamlit Cloud 배포 | 실행 및 접속 확인 |
| NFR-09 | 예측 정확도 | 등속도 예측 대비 ADE·FDE 비교(회전 구간 30% 개선 목표) | S06 회전 구간 측정 |

성능 측정 결과는 평균과 P95를 기록한다.

## 5. 위험 판정 요구사항
| 위험 단계 | 통합 CRI 범위 | 동작 |
|---|---|---|
| SAFE | CRI < 0.50 | 정상 표시 |
| WARNING | 0.50 <= CRI < 0.85 | 주의 경보 및 이벤트 기록 |
| CRITICAL | CRI >= 0.85 | 위험 경보 및 이벤트 기록 |

- CRI는 0~1 범위의 값으로 계산한다.
- TTC·DCPA 계산 시 접근·이탈 상태를 구분한다.
- 충돌 판정 거리와 안전 버블 기준은 시뮬레이션용 설정값으로 관리한다.
- 세부 계산식과 예외 처리는 `risk_rules.md`에 정의한다.
- 실제 산업현장의 안전 제어 기준으로 사용하지 않는다.
- 위험 단계는 통합 CRI로 판정한다.
